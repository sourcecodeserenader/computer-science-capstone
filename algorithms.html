Artifact Description

The artifact I selected for this enhancement is the client management application that began as CS 410 Software Reverse Engineering Project One. The original application was a small C++ console program recovered from a compiled binary. It contained five fixed clients, separate global variables for client names and service selections, a hard coded demonstration password, and repeated conditional logic for locating and updating records. I first enhanced this artifact in CS 499 Milestone Two for Software Design and Engineering. In that version, I reorganized the program into a more modular, object oriented design with a Client model, a ClientManager, an Authenticator, an InputValidator, and a Logger. I also added client creation and removal, stronger input validation, limited authentication attempts, environment variable credentials, and audit logging.

For Milestone Three I used the Milestone Two version as the starting point and expanded it specifically to demonstrate algorithms and data structures. The new version remains an in memory application on purpose because persistent storage is reserved for my later database enhancement. This separation lets each stage of the capstone show a different type of growth. The Milestone Three version now manages richer client records that include age, account balance, risk level, email, phone number, and active status in addition to the original client ID, name, and selected service.

Justification for Inclusion and Enhancement

I selected this artifact because it shows my growth especially clearly. The original program worked, but its design was small, rigid, and dependent on repeated logic. That made it a useful artifact for showing how I can analyze an existing system and improve it in stages rather than replacing it with an unrelated project. The Software Design and Engineering enhancement improved the architecture, while this enhancement focuses on how client data is organized, searched, sorted, filtered, ranked, summarized, and changed.

The most important structural change is replacing the single vector based client collection with an unordered map keyed by client ID. In the Milestone Two version locating a client required a linear search through the vector. In the new version, exact lookup by client ID uses the hash based primary structure and has average constant time behavior. I also added an ordered secondary index using map<string, set<int>>. The map keeps normalized client names ordered, and the set allows more than one client to share the same normalized name while preserving unique IDs. This secondary index supports exact name searches and prefix searches without forcing the program to scan every client name from the beginning.

I used lower bound on the ordered name index for prefix searching, stable sort for multiple sorted client views, generic predicate based filtering for reusable search criteria, and priority queue for Top K ranking operations. The application can now sort by ID, name, account balance, service type, and risk level; filter by service, risk, status, balance thresholds, or compound criteria; and rank the highest or lowest account balances. I also added portfolio analytics that calculate totals, averages, service distributions, risk distributions, minimum and maximum balances, and the median balance. Calculating the median requires sorting a separate collection of balances, which gave me another opportunity to think about algorithm cost instead of only program output.

Another major addition is an undo history implemented with stack<Action>. A stack matches the last in, first out behavior of an undo operation naturally. When a client is added, removed, or updated, the program stores enough before and after state to reverse the most recent mutation. I also added secondary index validation and rebuilding tools. These features are important because improving lookup performance by maintaining more than one structure introduces a new responsibility: the indexes must stay synchronized when records are inserted, removed, renamed, edited, or restored through undo.

The enhancement improved the artifact in both functionality and design depth. The application no longer demonstrates only basic CRUD behavior. It now demonstrates deliberate selection of data structures based on access patterns, reusable algorithms, time complexity trade offs, multi criteria searching and filtering, ranking, statistical aggregation, and consistency checking. The program also contains a structure statistics screen that reports the primary hash table size, bucket count, load factor, secondary index size, undo stack depth, and expected complexity of the major operations. I included that feature so the design decisions are visible and explainable rather than hidden behind menu output.

Course Outcomes

This enhancement most directly advances the third course outcome: designing and evaluating computing solutions using algorithmic principles and computer science practices while managing the trade offs involved in design choices. I met the goal I established for this category because I did more than substitute one container for another. I evaluated the operations the application performs and matched different structures to different needs. The unordered map favors fast exact ID access, the ordered map supports name ordering and prefix navigation, sets handle duplicate name references, vectors provide temporary sortable views, the priority queue supports bounded Top K ranking, and the stack models undo history.

The trade offs are also clearer to me after implementing the enhancement. The hash based primary store can improve average lookup speed, but it does not maintain useful ordering. The ordered secondary index adds search capability, but it uses additional memory and creates synchronization work whenever a client's name or record changes. Sorting copied views protects the primary storage structure, but creating and sorting those copies has its own time and memory cost. A bounded heap can find the top K clients without sorting the entire dataset, but it is more complex than a simple full sort. These are the kinds of choices I wanted this milestone to demonstrate.

The enhancement also supports the fourth outcome because I used standard C++ containers and algorithms to implement features that deliver practical value, including flexible search, ranking, analytics, and undo. It continues to support the fifth outcome through defensive input validation, limited authentication attempts, environment variable credentials, and audit logging inherited from Milestone Two. My written narrative and the organization of the code also contribute to the second outcome involving professional technical communication. Reflection on the Enhancement Process

The biggest thing I learned from this enhancement is that choosing a data structure is not about finding one container that is 'best.' It is about identifying the operations a system performs most often and deciding which trade offs are acceptable. My Milestone Two vector was simple and appropriate for a very small program, but it required linear searching for client IDs and did not give me an efficient way to support ordered prefix searches. Moving to an unordered map improved one type of access, but it immediately created another problem: hash tables do not provide the ordering needed for prefix navigation. That is why the secondary ordered index became necessary.

Maintaining multiple structures was also one of the most important challenges. Once the client record and the name index both represent parts of the same logical data, every mutation has to preserve their consistency. Renaming a client for example requires removing the old normalized name entry before adding the new one. Removing a client requires deleting both the primary record and its secondary index reference. Undo operations have to restore the correct state in both places. I responded to that challenge by centralizing insertion and deletion through helper functions and by adding validation and rebuilding tools for the name index.

The ranking and analytics features also made me think more carefully about whether an operation really needs a full sort. For ordinary sorted displays, creating a vector and using stable sort is straightforward and appropriate. For a Top K request, however, a bounded priority queue can keep only the most relevant candidates during processing. The analytics feature similarly combines one pass aggregation for totals, counts, minimums, and maximums with sorting only where it is needed to calculate the median. This helped me move from thinking about algorithms as isolated textbook exercises to thinking about how they work together inside an application.

I also learned that expanding functionality can create new engineering responsibilities. Adding richer client records made the searches and analytics more meaningful, but it also increased the amount of validation and state that the program has to manage. Adding undo behavior created the need to store previous state. Adding a secondary index improved retrieval but increased memory use and consistency requirements. Those consequences are useful because they gave me concrete examples of the trade offs described in the course outcomes.

At this stage I am satisfied that the enhancement has a distinct algorithms and data structures purpose and that it builds naturally on Milestone Two without taking over the role of the upcoming database milestone. I compiled the enhanced program using C++ 17 with warnings enabled and verified that the application starts, authenticates with the configured environment variables, displays the expanded menu, and exits cleanly. Before the final ePortfolio submission I will incorporate any instructor feedback, continue testing the individual search, sort, filter, ranking, analytics, undo, and index maintenance paths, and polish the code and narrative. My next major enhancement will be database persistence so that the same client management system can move from an in memory data model to persistent relational storage.

Complexity and implementation trade offs

Let n be the client count, u the distinct name count, p the matching name keys, k the returned or ranked records, and d the number of duplicate names in a key. Ignoring variable string lengths, identifier lookup is average O(1) with unordered_map and worst case O(n). Exact name lookup is O(log u + k) with expected constant time ID retrieval. Prefix lookup navigates the ordered index and then sorts its results, giving O(log u + p + k log k) under the expected hash lookup assumption. The final sort means the entire prefix operation should not be described only as O(log u + k).

Sorted views require O(n log n) comparisons with the normal temporary memory available to stable_sort and O(n) storage for the copied view. A full predicate filter scans O(n) records and may retain O(n) results. Analytics aggregation is O(n), while computing the median by sorting balances makes the full analytics operation O(n log n). The bounded heap ranks in O(n log k + k log k) time; its heap uses O(k) space, but the menu also creates an eligible vector, so end to end temporary storage includes O(n) records. Undo stack push and pop are constant time, excluding record copies and the name index maintenance needed to restore a change.

class InputValidator {
public:
    static int readIntInRange(
        const string& prompt,
        int minimum,
        int maximum) {

        while (true) {
            cout << prompt;

            string input;
            getline(cin, input);
            std::stringstream stream(input);

            int value = 0;
            char trailingCharacter = '\0';

            if ((stream >> value) &&
                !(stream >> trailingCharacter) &&
                value >= minimum &&
                value <= maximum) {
                return value;
            }

            cout << "Invalid input. Please enter a number from "
                << minimum << " through " << maximum << ".\n";
        }
    }

    static double readDoubleInRange(
        const string& prompt,
        double minimum,
        double maximum) {

        while (true) {
            cout << prompt;

            string input;
            getline(cin, input);
            std::stringstream stream(input);

            double value = 0.0;
            char trailingCharacter = '\0';

            if ((stream >> value) &&
                !(stream >> trailingCharacter) &&
                std::isfinite(value) &&
                value >= minimum &&
                value <= maximum) {
                return value;
            }

            cout << "Invalid input. Please enter a value from "
                << minimum << " through " << maximum << ".\n";
        }
    }

    static string readNonEmptyLine(const string& prompt) {
        while (true) {
            cout << prompt;

            string value;
            getline(cin, value);

            if (value.find_first_not_of(" \t\r\n") != string::npos) {
                return value;
            }

            cout << "Input cannot be blank. Please try again.\n";
        }
    }

    static bool readYesNo(const string& prompt) {
        while (true) {
            const string input = toLower(readNonEmptyLine(prompt));

            if (input == "y" || input == "yes") {
                return true;
            }

            if (input == "n" || input == "no") {
                return false;
            }

            cout << "Please enter yes/y or no/n.\n";
        }
    }

    static string toLower(string value) {
        std::transform(
            value.begin(),
            value.end(),
            value.begin(),
            [](unsigned char character) {
                return static_cast<char>(std::tolower(character));
            });

        return value;
    }
};

class Authenticator {
public:
    explicit Authenticator(const Logger& logger)
        : logger_(logger) {
    }

    bool authenticate() const {
        const string configuredUsername =
            readEnvironmentVariable("CS499_USERNAME");

        const string configuredPassword =
            readEnvironmentVariable("CS499_PASSWORD");

        if (configuredUsername.empty() || configuredPassword.empty()) {
            cout
                << "Authentication is not configured.\n"
                << "Set the CS499_USERNAME and CS499_PASSWORD environment "
                << "variables before running the program.\n";

            logger_.write("AUTH_CONFIGURATION_ERROR");
            return false;
        }

        for (int attempt = 1;
            attempt <= Constants::kMaxAuthenticationAttempts;
            ++attempt) {

            const string enteredUsername =
                InputValidator::readNonEmptyLine("Enter your username: ");

            const string enteredPassword =
                InputValidator::readNonEmptyLine("Enter your password: ");

            if (enteredUsername == configuredUsername &&
                enteredPassword == configuredPassword) {

                cout << "Authentication successful.\n\n";
                logger_.write("AUTH_SUCCESS username=" + enteredUsername);
                return true;
            }

            const int remainingAttempts =
                Constants::kMaxAuthenticationAttempts - attempt;

            cout << "Invalid credentials.";
            if (remainingAttempts > 0) {
                cout << " Attempts remaining: " << remainingAttempts;
            }
            cout << '\n';

            logger_.write(
                "AUTH_FAILURE attempt=" + std::to_string(attempt));
        }

        cout << "Maximum authentication attempts reached. Access denied.\n";
        logger_.write("AUTH_LOCKOUT");
        return false;
    }

private:
    static string readEnvironmentVariable(const char* name) {
#ifdef _MSC_VER
        char* value = nullptr;
        size_t length = 0;

        const errno_t result = _dupenv_s(&value, &length, name);
        if (result != 0 || value == nullptr) {
            return "";
        }

        const string environmentValue(value);
        std::free(value);
        return environmentValue;
#else
        const char* value = std::getenv(name);
        if (value == nullptr) {
            return "";
        }
        return string(value);
#endif
    }

    const Logger& logger_;
};

    void displayAnalytics() const {
        cout << "\nPortfolio Analytics\n";
        cout << "-------------------\n";

        if (clients_.empty()) {
            cout << "No client records are available.\n\n";
            return;
        }

        std::size_t brokerageCount = 0;
        std::size_t retirementCount = 0;
        std::size_t conservativeCount = 0;
        std::size_t moderateCount = 0;
        std::size_t aggressiveCount = 0;
        std::size_t activeCount = 0;

        double totalAssets = 0.0;
        double brokerageAssets = 0.0;
        double retirementAssets = 0.0;
        vector<double> balances;
        balances.reserve(clients_.size());

        const Client* highestClient = nullptr;
        const Client* lowestClient = nullptr;

        for (const auto& entry : clients_) {
            const Client& client = entry.second;

            totalAssets += client.accountBalance;
            balances.push_back(client.accountBalance);

            if (client.service == ServiceType::Brokerage) {
                ++brokerageCount;
                brokerageAssets += client.accountBalance;
            }
            else {
                ++retirementCount;
                retirementAssets += client.accountBalance;
            }

            switch (client.riskLevel) {
            case RiskLevel::Conservative:
                ++conservativeCount;
                break;
            case RiskLevel::Moderate:
                ++moderateCount;
                break;
            case RiskLevel::Aggressive:
                ++aggressiveCount;
                break;
            }

            if (client.active) {
                ++activeCount;
            }

            if (highestClient == nullptr ||
                client.accountBalance > highestClient->accountBalance) {
                highestClient = &client;
            }

            if (lowestClient == nullptr ||
                client.accountBalance < lowestClient->accountBalance) {
                lowestClient = &client;
            }
        }

        std::sort(balances.begin(), balances.end());

        double median = 0.0;
        const std::size_t count = balances.size();

        if (count % 2 == 1) {
            median = balances[count / 2];
        }
        else {
            median = (balances[count / 2 - 1] + balances[count / 2]) / 2.0;
        }

        const double average = totalAssets / static_cast<double>(count);

        cout << std::fixed << std::setprecision(2);
        cout << "Total clients: " << count << '\n';
        cout << "Active clients: " << activeCount << '\n';
        cout << "Inactive clients: " << (count - activeCount) << "\n\n";

        cout << "Service Distribution\n";
        cout << "  Brokerage: " << brokerageCount
            << " (" << percentage(brokerageCount, count) << "%)\n";
        cout << "  Retirement: " << retirementCount
            << " (" << percentage(retirementCount, count) << "%)\n\n";

        cout << "Asset Summary\n";
        cout << "  Total assets: $" << totalAssets << '\n';
        cout << "  Average balance: $" << average << '\n';
        cout << "  Median balance: $" << median << '\n';
        cout << "  Brokerage assets: $" << brokerageAssets << '\n';
        cout << "  Retirement assets: $" << retirementAssets << '\n';

        if (brokerageCount > 0) {
            cout << "  Avg. Brokerage balance: $"
                << (brokerageAssets / static_cast<double>(brokerageCount))
                << '\n';
        }

        if (retirementCount > 0) {
            cout << "  Avg. Retirement balance: $"
                << (retirementAssets / static_cast<double>(retirementCount))
                << '\n';
        }

        if (highestClient != nullptr) {
            cout << "  Highest balance: " << highestClient->name
                << " ($" << highestClient->accountBalance << ")\n";
        }

        if (lowestClient != nullptr) {
            cout << "  Lowest balance: " << lowestClient->name
                << " ($" << lowestClient->accountBalance << ")\n";
        }

        cout << "\nRisk Distribution\n";
        cout << "  Conservative: " << conservativeCount << '\n';
        cout << "  Moderate: " << moderateCount << '\n';
        cout << "  Aggressive: " << aggressiveCount << "\n\n";
    }

    // -------------------------------------------------------------------------
    // Undo Stack
    // -------------------------------------------------------------------------

    void undoLastChange() {
        if (undoHistory_.empty()) {
            cout << "There is no change available to undo.\n\n";
            return;
        }

        const Action action = undoHistory_.top();
        undoHistory_.pop();

        switch (action.type) {
        case ActionType::Add:
            if (action.after.has_value()) {
                eraseClient(action.after->id);
            }
            break;

        case ActionType::Remove:
            if (action.before.has_value()) {
                insertClient(*action.before);
            }
            break;

        case ActionType::Update:
            if (action.before.has_value() && action.after.has_value()) {
                eraseClient(action.after->id);
                insertClient(*action.before);
            }
            break;
        }

        logger_.write("UNDO action=" + action.description);
        cout << "Undo completed: " << action.description << ".\n\n";
    }

    // Primary structure: average O(1) exact lookup by numeric ID.
    unordered_map<int, Client> clients_;

    // Secondary ordered index: O(log n) key navigation plus returned matches.
    // The set allows duplicate normalized names while preserving unique IDs.
    map<string, set<int>> nameIndex_;

    // LIFO history is a natural fit for undo operations.
    stack<Action> undoHistory_;

    int nextClientId_ = 1;
    const Logger& logger_;

    // -------------------------------------------------------------------------
    // Core Storage Helpers
    // -------------------------------------------------------------------------

    void seedClient(const Client& client) {
        insertClient(client);
    }

    void insertClient(const Client& client) {
        clients_[client.id] = client;
        addToNameIndex(client.name, client.id);

        if (client.id >= nextClientId_) {
            nextClientId_ = client.id + 1;
        }
    }

    bool eraseClient(int clientId) {
        const auto match = clients_.find(clientId);
        if (match == clients_.end()) {
            return false;
        }

        removeFromNameIndex(match->second.name, clientId);
        clients_.erase(match);
        return true;
    }

    Client* findClientById(int clientId) {
        const auto match = clients_.find(clientId);
        if (match == clients_.end()) {
            return nullptr;
        }
        return &(match->second);
    }

    const Client* findClientById(int clientId) const {
        const auto match = clients_.find(clientId);
        if (match == clients_.end()) {
            return nullptr;
        }
        return &(match->second);
    }

    bool clientExists(int clientId) const {
        return clients_.find(clientId) != clients_.end();
    }

    int readExistingClientId(const string& prompt) const {
        while (true) {
            const int clientId = InputValidator::readIntInRange(
                prompt,
                1,
                std::numeric_limits<int>::max());

                return clientId;

            cout << "No client exists with ID " << clientId
                << ". Please try again.\n";
        }
    }

    // -------------------------------------------------------------------------
    // Name Index Helpers
    // -------------------------------------------------------------------------

    static string normalizeName(string value) {
        value = InputValidator::toLower(value);

        const std::size_t first = value.find_first_not_of(" \t\r\n");
        if (first == string::npos) {
            return "";
        }

        const std::size_t last = value.find_last_not_of(" \t\r\n");
        return value.substr(first, last - first + 1);
    }

    void addToNameIndex(const string& name, int clientId) {
        nameIndex_[normalizeName(name)].insert(clientId);
    }

    void removeFromNameIndex(const string& name, int clientId) {
        const string normalized = normalizeName(name);
        const auto indexMatch = nameIndex_.find(normalized);

        if (indexMatch == nameIndex_.end()) {
            return;
        }

        indexMatch->second.erase(clientId);

        if (indexMatch->second.empty()) {
            nameIndex_.erase(indexMatch);
        }
    }

    void rebuildNameIndex() {
        nameIndex_.clear();

        for (const auto& entry : clients_) {
            const Client& client = entry.second;
            addToNameIndex(client.name, client.id);
        }
    }

    void validateNameIndex() const {
        bool valid = true;
        std::size_t indexedIds = 0;

        for (const auto& entry : nameIndex_) {
            const string& normalizedName = entry.first;
            const set<int>& ids = entry.second;

            for (int clientId : ids) {
                ++indexedIds;

                const Client* client = findClientById(clientId);
                if (client == nullptr ||
                    normalizeName(client->name) != normalizedName) {
                    valid = false;
                }
            }
        }

        for (const auto& entry : clients_) {
            const Client& client = entry.second;
            const string normalized = normalizeName(client.name);
            const auto nameMatch = nameIndex_.find(normalized);

            if (nameMatch == nameIndex_.end() ||
                nameMatch->second.find(client.id) == nameMatch->second.end()) {
                valid = false;
            }
        }

        cout << "\nName Index Validation\n";
        cout << "---------------------\n";
        cout << "Primary client records: " << clients_.size() << '\n';
        cout << "Indexed client references: " << indexedIds << '\n';
        cout << "Index status: " << (valid ? "VALID" : "INVALID") << "\n\n";
    }

    void searchByNamePrefix() const {
        const string prefix = normalizeName(
            InputValidator::readNonEmptyLine("Name prefix: "));

        vector<Client> results;

        // lower_bound jumps directly to the first ordered key that could match.
        // This avoids scanning every name key from the beginning of the map.
        auto iterator = nameIndex_.lower_bound(prefix);

        while (iterator != nameIndex_.end() &&
            startsWith(iterator->first, prefix)) {

            for (int clientId : iterator->second) {
                const Client* client = findClientById(clientId);
                if (client != nullptr) {
                    results.push_back(*client);
                }
            }

            ++iterator;
        }

        std::stable_sort(
            results.begin(), results.end(),
            [](const Client& left, const Client& right) {
                return normalizeName(left.name) < normalizeName(right.name);
            });

        displayClientCollection("Prefix Search Results", results);
    }

    static bool startsWith(const string& value, const string& prefix) {
        return value.size() >= prefix.size() &&
            value.compare(0, prefix.size(), prefix) == 0;
    }

    // -------------------------------------------------------------------------
    // Generic Filtering
    // -------------------------------------------------------------------------

    template <typename Predicate>
    vector<Client> filterClients(Predicate predicate) const {
        vector<Client> results;

        for (const auto& entry : clients_) {
            const Client& client = entry.second;
            if (predicate(client)) {
                results.push_back(client);
            }
        }

        std::stable_sort(
            results.begin(), results.end(),
            [](const Client& left, const Client& right) {
                return left.id < right.id;
            });

        return results;
    }

    // -------------------------------------------------------------------------
    // Top-K Ranking Algorithms
    // -------------------------------------------------------------------------

    struct MinBalanceComparator {
        bool operator()(const Client& left, const Client& right) const {
            if (left.accountBalance != right.accountBalance) {
                return left.accountBalance > right.accountBalance;
            }
            return left.id > right.id;
        }
    };

    struct MaxBalanceComparator {
        bool operator()(const Client& left, const Client& right) const {
            if (left.accountBalance != right.accountBalance) {
                return left.accountBalance < right.accountBalance;
            }
            return left.id > right.id;
        }
    };

    static vector<Client> getTopKByBalance(
        const vector<Client>& source,
        int k) {

        priority_queue<
            Client,
            vector<Client>,
            MinBalanceComparator> heap;

        for (const Client& client : source) {
            heap.push(client);

            if (static_cast<int>(heap.size()) > k) {
                heap.pop();
            }
        }

        vector<Client> results;
        while (!heap.empty()) {
            results.push_back(heap.top());
            heap.pop();
        }

        std::sort(
            results.begin(), results.end(),
            [](const Client& left, const Client& right) {
                return left.accountBalance > right.accountBalance;
            });

        return results;
    }

    static vector<Client> getBottomKByBalance(
        const vector<Client>& source,
        int k) {

        priority_queue<
            Client,
            vector<Client>,
            MaxBalanceComparator> heap;

        for (const Client& client : source) {
            heap.push(client);

            if (static_cast<int>(heap.size()) > k) {
                heap.pop();
            }
        }

        vector<Client> results;
        while (!heap.empty()) {
            results.push_back(heap.top());
            heap.pop();
        }

        std::sort(
            results.begin(), results.end(),
            [](const Client& left, const Client& right) {
                return left.accountBalance < right.accountBalance;
            });

        return results;
    }

            << std::setw(14) << "Risk"
            << std::setw(9) << "Status"

    static string truncate(const string& value, std::size_t maxLength) {
        if (value.size() <= maxLength) {
            return value;
        }

        if (maxLength <= 3) {
            return value.substr(0, maxLength);
        }

        return value.substr(0, maxLength - 3) + "...";
    }

        cout << "Undo stack depth: " << undoHistory_.size() << "\n\n";

        cout << "Expected complexity characteristics:\n";
        cout << "  ID lookup: average O(1) using unordered_map\n";
        cout << "  Exact indexed name lookup: O(log n + k)\n";
        cout << "  Prefix index navigation: O(log n + k)\n";
        cout << "  Sorted views: O(n log n)\n";
        cout << "  Full predicate filtering: O(n)\n";
        cout << "  Analytics aggregation: O(n), plus O(n log n) for median\n";
        cout << "  Top-K ranking: O(n log k) using a bounded heap\n";
        cout << "  Undo push/pop: O(1), excluding index maintenance\n\n";
    }

    // -------------------------------------------------------------------------
    // Shared Input Helpers
    // -------------------------------------------------------------------------

    static ServiceType readServiceType() {
        const int serviceChoice = InputValidator::readIntInRange(
            "Select service (1 = Brokerage, 2 = Retirement): ",
            Constants::kMinServiceChoice,
            Constants::kMaxServiceChoice);

        return static_cast<ServiceType>(serviceChoice);
    }

    static RiskLevel readRiskLevel() {
        const int riskChoice = InputValidator::readIntInRange(
            "Select risk level (1 = Conservative, 2 = Moderate, 3 = Aggressive): ",
            Constants::kMinRiskChoice,
            Constants::kMaxRiskChoice);

        return static_cast<RiskLevel>(riskChoice);
    }

    static double percentage(std::size_t part, std::size_t whole) {
        if (whole == 0) {
            return 0.0;
        }

        return (static_cast<double>(part) /
            static_cast<double>(whole)) * 100.0;
    }
};

            switch (choice) {

                clientManager_.displayAllClients();
                break;

            case 2:
                clientManager_.addClient();
                break;

            case 3:
                clientManager_.editClient();
                break;

            case 4:
                clientManager_.removeClient();
                break;

            case 5:
                clientManager_.searchMenu();
                break;

            case 6:
                clientManager_.filterMenu();
                break;

            case 7:
                clientManager_.sortMenu();
                break;

            case 8:
                clientManager_.rankingsMenu();
                break;

            case 9:
                clientManager_.displayAnalytics();
                break;

            case 10:
                clientManager_.undoLastChange();
                break;

                break;

        }
