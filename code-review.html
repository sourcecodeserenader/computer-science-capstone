What the review covers

The baseline authenticates a user, displays five clients and changes a service choice. The review explains the global variables, repeated conditions, unsafe input and embedded credential behavior before planning modular design, purpose selected data structures and database persistence.

The historical source contains the original insecure credential comparison for review. The later enhancements change that behavior. It is not presented as a recommended authentication design.
